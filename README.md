# Unity Pywal

Unity Pywal is a Unity Editor package that applies colors from `pywal` to the Unity Editor.

## What It Does

- Reads a palette from `~/.cache/wal/colors.json`
- Generates Unity Editor extension styles for the current skin
- Can watch the palette file and update the theme automatically

## Use

Open `Preferences > Unity Pywal` to:

- Enable or disable syncing
- Set a custom palette path
- Choose whether to apply on startup
- Choose whether to watch the palette file
- Apply the current palette manually
